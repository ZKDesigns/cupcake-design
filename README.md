# 🧁 Voňavé Cupcakes

Krásný interaktivní web o cupcakes v teplých oranžových tónech.

## Co je uvnitř

- Hlavní 3D cupcake s plovoucí animací a září
- Galerie dalších cupcakes s 3D tilt efektem
- Pohybující se posyp (sprinkles) po celé stránce
- Recepty přeložené do češtiny
- Tmavý teplý design s oranžovými akcenty
- Plynulé scroll animace a glow efekty

## Jak spustit

Jednoduše otevři `index.html` v prohlížeči  
nebo:

```bash
python -m http.server 8000
